# 致小米公司的一封信

> 英文镜像：[letter-xiaomi.en.md](letter-xiaomi.en.md)  
> 项目索引：[README.md](../README.md)

尊敬的小米公司：

先别空谈「人们会拿它做什么」。

不如聊聊你们自己给 MiMo Desktop 的广告词：

> *「面向专业人士的一体化 AI 桌面应用——高质量办公、设计、编码与多模态创作。」*

是啊。

办公。

那么做专业办公的人，会用什么笔记本？

**ThinkPad！** 🤓👆

而且这些 ThinkPad——以及其他专业 Windows 笔记本——正在越来越多地搭载 ARM64 处理器。

我不会假装已经完全知道 Copilot+ PC 会把我们的生活带向何方。

但有一件事越来越难被忽略：

**Windows on ARM 正在进入专业计算领域。**

已经出现的机器包括 **ThinkPad T14s Gen 6**，以及越来越多的 Windows on ARM 设备。

如果 MiMo Desktop 的定位是面向专业人士的一体化 AI 桌面应用，支持 Windows on ARM 终究应当成为这个故事的一部分。

而且，说来也巧……

我碰巧有一台 Xiaomi Book S。

于是我自己试了试。

我取来 ARM64 Electron 运行时，重建了必要的开发环境，处理掉架构相关的部分，让 MiMo Desktop 原生跑在 Windows on ARM 上。

不是因为小米叫我这么做。

也不是因为我有源码。

只因为我好奇：

> ***「这到底能有多难？」***

至少有一部分，似乎是可能的。

所以，小米——

**我做了。**

**现在轮到你们了。** 🤓👍
