## 测量注意事项（引用这组数时必须一并说明）

1. **T1 判定含 DOM 扫描**：探针每 150ms 执行一次较重的 `querySelectorAll` 扫描，且要求 subRows≥3 连续 2 次稳定（约 300ms 地板）。x64 模拟下扫描本身更慢，**T1 差距可能部分来自探针开销而非界面就绪**。
2. **Code Cache 每轮清空**：强制冷 JIT，对 x64 模拟更不利；这是刻意的冷启动口径，不代表热启动体验。
3. **mainToList 是参考值，不是对比指标**：平台对比只看 T1 绝对时间（见 `AGENTS.md`）。
4. **engFetch 与 T1 强耦合**：两侧 EngEnd 都紧贴 T1（9354 vs 9680 / 24936 vs 25656），列表就绪基本被 engine 拉取闸住。
